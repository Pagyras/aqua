# Изображения

Сейчас в проекте есть два типа изображений:

1. `assets/img/projects/` — реальные фото проектов, перенесены из архива с фото.
2. В карточках продукции и hero пока оставлены текущие внешние URL, чтобы сайт сразу выглядел как раньше.

Когда загрузите свои файлы:
- положите изображения продукции в `assets/img/products/`;
- положите hero-фото в `assets/img/hero/`;
- замените внешние ссылки в `.njk` страницах на локальные пути вида `assets/img/products/file.png`.

Есть заглушка: `assets/img/placeholders/placeholder.svg`.
